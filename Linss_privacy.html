1. Application Description

Linss is a local file management tool designed to help users browse, create, copy, move, delete, and organize files and folders stored on their device.

The application is designed with a fully local-first architecture and does not rely on cloud services or user accounts.

2. Information We Do Not Collect

During the use of Linss, the application does not collect, store, or transmit any of the following data:

- Personal information such as name, phone number, or email address;
- Any files stored on the user’s device (documents, photos, videos, audio, etc.);
- File names or directory structures;
- Location data or device identifiers (such as IMEI, IDFA, etc.);
- Any usage behavior, analytics, or activity logs.

3. Data Processing

1. All file operations are performed locally on the user’s device;
2. No file content is uploaded to any server;
3. The developer has no access to user files or file system data;
4. All actions such as create, delete, move, or rename occur only on local storage.

6. File Security Notice
